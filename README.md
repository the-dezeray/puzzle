# Student Task Manager

A simple task management application developed for
educational purposes. It helps students keep track of
assignments, deadlines, and group project progress.

## Features

- Create, edit, and delete tasks
- Organize tasks by course and due date
- Track progress toward completion
- Simple local storage persistence

## Running the project

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

> Everything you   need is already   here.

Just follow the breadcrumbs and you will know where to go next.

## Project structure

```
src/          application source code
components/   shared UI components
config/       environment and backup configuration
assets/       media and static files
public/       public web assets
scripts/      build and utility scripts
docs/         project documentation
```
